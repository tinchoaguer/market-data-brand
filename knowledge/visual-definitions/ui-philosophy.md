# Market Data UI Philosophy

Market Data is not a trading platform.

Market Data is not Bloomberg.

Market Data is not TradingView.

Market Data is an analysis workstation.

Every screen must answer one question.

Never show more than one primary action.

Every metric must have a reason.

Every score must be explainable.

Progressive disclosure over information density.

One Symbol at a time.

The Symbol is always the protagonist.

Analysis precedes raw numbers.

Numbers are evidence, not the message.
